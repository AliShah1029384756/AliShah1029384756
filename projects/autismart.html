AutiSmart

AI-assisted autism-support platform developed as a team Final Year Project at FAST-NUCES.

Team FYP · Public RepositoryFinal team FYP · completed

Why It Matters

AutiSmart was built as a Final Year Project to explore how software engineering, AI-assisted interaction, and healthcare-oriented workflows can be combined into one practical platform. The project was developed, run, and presented collaboratively by the FYP team at FAST-NUCES.

Project Overview

AutiSmart is a hybrid web-based platform designed to support screening-stage classification, symptom tracking, therapy support, progress monitoring, awareness material and AI-assisted interaction for parents, caregivers, therapists and related users.

Core Modules

  • ASD Stage Detector: screening-stage classification workflow
  • Symptom Tracking: structured symptom information and progress context
  • Therapy Recommender: therapy-support workflow
  • Parent & Expert Portal: role-oriented coordination concepts
  • Progress Dashboard: progress monitoring and reporting
  • Awareness Material: Urdu/English support content
  • AI Chat Assistant: AI-assisted interaction
  • Text/Audio/Video Analysis: multimodal/agentic AI concepts
  • Data Export: structured information export
  • Therapy Games: activities for initial/middle stages

Technology Stack

Frontend

HTML, CSS and JavaScript.

Backend

Node.js and Express with an MVC-style backend architecture.

Database

MongoDB for application data.

AI

Multimodal and agentic AI concepts integrated into selected support workflows.

Engineering Documentation

The project documentation includes software-engineering artifacts such as SRS, vision documentation, stakeholder profiles, use cases, activity/swimlane diagrams, SSDs, component/package diagrams, DFD levels, domain model, class diagram and PlantUML representations.

What This Project Demonstrates

  • Full-stack product development in a healthcare-oriented domain
  • Integration of AI-assisted functionality into application workflows
  • Role-oriented application architecture and structured workflows
  • Progress monitoring, reporting and therapy-support product thinking
  • Collaborative Final Year Project development and presentation at FAST-NUCES
