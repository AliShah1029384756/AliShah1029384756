SchoolIEP

Education-domain application focused on structured Individualized Education Plan (IEP) workflows.

A-Tier · Public Repository Case Study · No public live deployment currently listed

At a Glance

SchoolIEP demonstrates full-stack engineering applied to education workflows: student records, IEP lifecycle management, learning goals, parent coordination and progress reporting. It is an academic/software-engineering project and is not presented as a certified institutional records system.

Core Workflow Areas

  • IEP Lifecycle: structured creation and management workflows
  • Student Records: organized student information
  • Parent Profiles: parent coordination and profile context
  • Learning Goals: goal creation and tracking
  • Progress Reporting: period-based progress reports
  • Protected Workflows: authenticated access to domain operations
  • React Dashboard: dashboard-oriented user experience

Technology & Engineering

Frontend

React + Vite + JavaScript with dashboard-oriented interfaces.

Backend

Node.js + Express for REST APIs and application workflows.

Data

MongoDB + Mongoose for structured application data and relationships.

Security

JWT authentication and protected workflows.

Architecture

React/Vite frontend → REST API → Node/Express backend → MongoDB/Mongoose. Backend boundaries cover authentication, students, parents, IEPs, goals/progress and reporting.

Engineering Focus

  • Modelling a multi-stakeholder education workflow as clear application modules
  • Managing IEP lifecycle state, goals and progress information
  • Using authentication to protect domain workflows
  • Keeping the project positioned as an academic/software-engineering system rather than a certified institutional records product

What It Demonstrates

  • Education-domain product thinking
  • Full-stack CRUD and relational document/data relationships
  • REST API integration and MongoDB/Mongoose usage
  • Authentication and dashboard workflows
  • Domain-specific progress reporting

Repository Status

The project repository is public and can be reviewed directly on GitHub. No public live deployment is currently listed.
