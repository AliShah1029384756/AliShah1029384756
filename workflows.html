My working loop

From an idea to a working result

01 · Understand

Clarify the problem, audience, constraints, expected output and what a useful first version should do.

02 · Research

Use documentation, search, tutorials, examples and AI assistants to understand the domain and available approaches.

03 · Select & Orchestrate

Choose suitable tools for planning, explanation, coding, debugging or review. Give each task clear context and constraints.

04 · Implement

Turn the plan into interfaces, application logic, integrations or a hardware/software prototype.

05 · Test & Review

Run the work, inspect errors, check requirements and evaluate whether the output behaves as intended.

06 · Iterate & Explain

Refine the result, document important decisions and explain the process so the work can be understood and improved.

What AI contributes — and what I remain responsible for

AI can help me

Explore options, explain unfamiliar concepts, draft code, suggest debugging paths, compare approaches and accelerate repetitive work.

My responsibility

Define the goal, provide accurate context, choose what to use, integrate components, test behavior, catch mistakes and understand the final result.

I treat generated output as a starting point for review, not as proof that a feature works. The value is in combining tools with problem understanding, practical implementation and iteration.

Learning is part of the work

My development is supported by FAST-NUCES coursework, independent exploration, documentation, Google Search, YouTube tutorials, programming-learning resources and hands-on experimentation. I am comfortable learning a tool when a project or assignment requires it, then applying that learning to a practical task.
